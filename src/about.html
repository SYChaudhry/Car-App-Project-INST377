About Gearly

Gearly is a car maintenance web application that helps users track vehicles, record service history, check safety recalls, and find nearby service shops.

Project Purpose

Many car owners have trouble keeping track of vehicle information, maintenance records, and important safety updates. Gearly brings these tools together in one simple dashboard so users can stay more organized and make better decisions about their vehicles.

Main Features

Garage Users can add, edit, remove, and view vehicles saved in the database.
Service History Users can record maintenance services such as oil changes, tire rotations, brake checks, and other repairs.
Recall Check Gearly checks saved vehicles against NHTSA recall data using the vehicle year, make, and model.
Nearby Shops Users can search for nearby vehicle service locations using a city, ZIP code, or address. Results are shown on an interactive map.

Technology Used

Gearly is built with HTML, CSS, JavaScript, Node.js, Express, Supabase, Fetch API, SweetAlert2, Leaflet.js, NHTSA Recall API, Nominatim, and Geoapify Places API.

Target Users

Gearly is designed for everyday car owners, students, first-time car owners, and anyone who wants a simple way to organize vehicle maintenance information.
